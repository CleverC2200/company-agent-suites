# 预测复核与交付

读 [报告模板](../../references/report-template.md) 与 [规则与冲突](../../references/rules-and-conflicts.md)，原文重点查 [V2 §4.4、§5、§7](../../references/sales-ontology-v2.md)。

逐行检查月份映射、客户/SKU 唯一键、来源与截止时间、单位转换、权重、公式中间值及新产品分支。供应商、仓库、区域聚合不可重复计入同一发货；纠偏值按节点继承，禁止跨审批节点求和。status=5 为品类已审批待回写，status=10 才是回写完成；二者不是预测质量证明。

六类失真分别列出：经销库存不全、DC/直营缺终端抓手、大日期无效库存、新品节奏不稳、新老品切换、缺货压低发货。无证据不自动修正；缺货期发货不等于真实需求。大日期政策标签与库存风险独立存储；ABC、仓库类型或规则版本缺失时不能确定大日期等级。短保品禁止套常规周转；工厂周转与经销商全链时间预算分开。

按状态汇总 calculated/partial/blocked/excluded，报告可售总数、普通交集、候选入选、已计算和阻断数量；另列数量权重覆盖率，分母不全则 unknown。partial 基线不混入“最终预测”合计，单位不同不相加，排除/阻断行不以零填补。不要把材料中的 2199 SKU 当实时覆盖分母（分项 1013+1180=2193 本身不闭合）。

如有已冻结的预测快照和完整实际值，可做离线回测，先确认发货或动销作为 actual、期间、单位和评价集合。禁止使用预测生成后才可见的数据拟合当时预测。MAE=平均绝对误差；WAPE=Σ|预测−实际|/Σ|实际|；bias=Σ(预测−实际)/Σ|实际|。实际绝对值总和为 0 时 WAPE/bias 为 unknown，保留 MAE 和样本数。固定同一集合与朴素基线比较，披露排除行、缺货偏差及覆盖。以上是工程评测指标，不是 §3.19 尚未定义的公司“计划准确率”，不设擅自通过阈值，不造置信度百分比。

按报告模板输出，建议只陈述可验证的下一步。本套件没有业务写入、真实 MCP 或自动 UI 注入能力；只有得到真实执行回执才能报告外部动作成功。
